# literaturverwaltungsmigration
Workaround für den Umstieg von Citavi auf Zotero unter Windows. Sie nehmen mit, was der Standardimport verliert: die Art jedes Wissenselements (wörtliches Zitat, indirektes Zitat, Zusammenfassung, Kommentar), Kategorien und Schlagwörter der Zitate, Verweise zwischen Quellen sowie die Verknüpfung von Sammelband und Beitrag.
